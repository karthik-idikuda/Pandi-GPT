# Pandi-GPT

Custom GPT-powered conversational AI assistant with domain-specific knowledge, context management, and natural language understanding.

## Features

- Domain-specific knowledge base integration
- Multi-turn conversation with context retention
- Streaming response generation
- Conversation export and history
- Configurable personality and response style

## Tech Stack

JavaScript, OpenAI API, React, Node.js, Express

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/karthik-idikuda/Pandi-GPT.git
cd Pandi-GPT
npm install
```

### Usage

```bash
npm start
```
